【二、三大核心工具功能明细】
--------------------------------------------------------------------------------
1. 字母大小写与命名规范转换器 (Case & Text Converter):
   - 支持 UPPERCASE、lowercase、Title Case、Sentence case、Capitalize Each Word
   - 编程命名规范转换: camelCase (驼峰)、PascalCase (大驼峰)、snake_case (下划线)、
     kebab-case (短横线)、CONSTANT_CASE (常量大写)、dot.case 等 21+ 种格式
   - 支持空行清理、多余空格合并、一键剪贴板复制。

2. Cron 表达式可视化解析与未来时间模拟器 (Cron Visualizer):
   - 支持 Linux 5位标准、Spring 6位框架规范、Quartz 7位企业级调度表达式
   - 独家智能工作日识别、L、W、# 等高级特殊字符本地化口语级翻译
   - 动态推算并渲染未来 5 次真实精准执行时间轴。

3. JSON 在线格式化、语法校验与 TS 生成器 (JSON Processor):
   - 毫秒级 JSON 格式化、压缩、转义与反转义
   - 精确到行列号的 6 国语言语法错误高亮提示
   - 递归类型推断算法: 智能合并数组异构对象、递归去重哈希生成 TypeScript 接口定义。

【四、日常开发与全自动部署流程 (CI/CD)】
--------------------------------------------------------------------------------
1. 本地启动开发服务器:
   cd D:\jsworkspace\text-converter-toolkit
   npm run dev
   (浏览器打开: http://127.0.0.1:3000)

2. 本地全套自动化质量测试 (191 项测试用例):

3. 提交发布新代码 (全自动云端构建):

   git commit -m "更新说明"
   git push origin main

   ★ 工作机制:
     当你执行 git push 后，GitHub 会自动触发 Webhook 通知 Cloudflare；
     Cloudflare 云端容器会在 20~30 秒内全自动拉取、构建并发布到全球公网，
     无需人工在网页上传任何文件！
